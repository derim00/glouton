GLOUTON : installateur pour NumWorks n0110, n0115 et n0120 (Mac)
===================================================

1. Une seule fois, dans le Terminal (avec Homebrew, https://brew.sh) :

       brew install libusb dfu-util

   Les jeux déjà dans le dossier games/ sont prêts à installer.
   Pour en ajouter d'autres (.nwa), il faut aussi :

       brew install --cask gcc-arm-embedded

2. Double-clique sur « Installer GLOUTON.command ».
   (La première fois, macOS peut le bloquer : clic droit > Ouvrir > Ouvrir.)
   La page de l'installateur s'ouvre dans ton navigateur.

3. Branche la calculatrice en USB et appuie sur Reset au dos :
   elle redémarre sur le système officiel (slot A).

4. Quand le voyant passe au vert, glisse tes jeux .nwa dans la page
   si tu veux, puis clique sur « Installer GLOUTON ».

GLOUTON s'installe dans le slot B : le système officiel (slot A) n'est
jamais modifié. Après un Reset, la calculatrice revient sur le système
officiel ; il suffit de relancer l'installation pour retrouver GLOUTON.

Les commandes de GLOUTON
-------------------------

Flèches gauche / droite  se déplacer
Haut ou EXE ............ sauter (maintiens pour sauter plus haut)
Bas .................... s'écraser (en l'air : plongeon)
OK ..................... la langue : manger le bonbon (l'appli) ou le
                         biscuit (le résultat) visé
Retour ................. le frigo : toutes les applis et tous les jeux
Boîte à outils ......... son carnet de santé (1 : LED, 2 : écran vivant)
1 2 3 4 5 .............. changer de décor (Jardin, Nuit, Volcan, Espace,
                         Aquarium)
6 ...................... le décor DISCO (secret : fais-le grandir)
Var .................... mode photo (cache les jauges)

Les touches magiques
--------------------

x² gonfler (5 fois : il explose)     √ dégonfler
×  se cloner                          ÷ fusionner les clones
sin danser                            cos changer de costume
tan bronzer                           i devenir imaginaire
-  gravité négative                   ln dormir
effacer : le chatouiller              + un en-cas
Ans une blague                        π la fête du π

Fais des calculs dans l'appli Calculs : en revenant, Glouton mange tes
résultats. Essaie 6×7, 0/0, 1+1, 6×111...
